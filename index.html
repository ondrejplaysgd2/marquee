v1.0.0 · Windows x64

Everything you need

No accounts, no cloud, no tracking. Just your films, beautifully organized.

🔍

Smart scanning

Finds films in Downloads and any folder you add. Parses title, year, resolution and audio language from file names automatically.

🎞

Generated poster art

Every film gets a unique gradient poster with a matching monogram — no internet, no API. Drop a .jpg next to the file to use your own.

☆

Favorites & collections

Group films any way you like. Rename collections freely — a hidden slug keeps internal references clean. Favorite anything with one click.

⏺

Continue watching

Resume where you left off. Progress is saved as you watch and surfaced on the Home page for quick pick-up.

🎬

Cinematic player

Letterboxed frame, film-grain overlay, auto-hiding controls. Seek, speed, volume — all at your fingertips. Fullscreen hides the cursor too.

📡

VLC fallback

Unusual codec? Subtitles only VLC can handle? Open in VLC with one click from the context menu or detail view.

Get started

Portable

View release
3

From source

git clone https://github.com/ondrejplaysgd2/marquee.git
cd marquee
npm install
npm start
Optional: install VLC to play any format the built-in engine can't decode.
